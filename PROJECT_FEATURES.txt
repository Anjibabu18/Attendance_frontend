MODULE 1: AUTHENTICATION & ACCESS CONTROL (5 Features)
================================================================================

1. Multi-Role RBAC Authentication
   - Role-Based Access Control supporting 4 distinct roles: Admin, HR, Manager,
     and Employee.
   - Separate dashboards, navigational hierarchies, and security permissions for
     each role.

2. WebAuthn Biometric Authentication
   - Passwordless login using biometric hardware (Apple Touch ID, Face ID,
     Windows Hello, or Android Fingerprint).
   - Secure Enclave cryptographic key generation and validation.

3. 1-Click Demo Accounts Switcher
   - Quick-fill buttons on the login screen for 🛡️ Admin, 👩‍💼 HR, and 👨‍💼 Employee.
   - Enables instant evaluation and role-switching without manual credential entry.

4. Persistent JWT Session Management & Auto-Refresh
   - Secure token storage, expiration detection, silent token refresh, and
     automatic redirection on session timeout.

5. Route Guard Protection & Background Route Preloading
   - Prevents unauthorized role access with client-side route guards.
   - Preloads target role bundles using requestIdleCallback for instant 0ms transitions.
